# FluxFrame ⚡️

تطبيق ويب متكامل مصمم خصيصاً لاستوديو **FluxFrame**، مبني بأحدث تقنيات **Next.js 14 (App Router)** مع **TypeScript** و **Tailwind CSS**. يدعم **اللغتين العربية والإنجليزية بالكامل** بتبديل فوري، مع تصميم راقٍ واتجاه RTL/LTR متوافق مع أعلى معايير الويب.

---

## 🌟 الخدمات الرئيسية والأسعار

### 1. باقة الهوية البصرية المتكاملة للمشاريع (Full Brand Identity) — **1,000 ج.م**
- كل ما تحتاجه لإطلاق علامتك التجارية من الصفر باحترافية كاملة.
- **ملفات الشعار المصدرية كاملة** بجميع الصيغ: (Vector SVG, PNG مفرغ شفاف, PDF عالي الجودة جاهز للطباعة).
- **موك آبس احترافية واقعية شاملة**: (كروت العمل، المراسلات، الأكياس والتغليف، اللافتات، اليونيفورم).
- دليل الهوية البصرية الكامل (Brand Guidelines) متضمناً الألوان والخطوط والأوامر الهندسية الدقيقة للذكاء الاصطناعي (Prompts).

### 2. صناعة فيديوهات الريلز وبوستات السوشيال ميديا بالذكاء الاصطناعي (AI Content Studio)
- **الأسعار الفردية المرنة:**
  - **100 إلى 200 ج.م** لكل فيديو ريلز / شورتس بالذكاء الاصطناعي مع تعليق صوتي ومؤثرات.
  - **20 إلى 50 ج.م** لكل تصميم بوست / منشور إعلاني متناسق مع هوية البراند.
- **3 باقات توفيرية جاهزة للطلب المباشر:**
  - **باقة الانطلاق (Starter):** 850 ج.م (5 ريلز فيديو AI + 10 بوستات وتصاميم).
  - **باقة النمو والمبيعات (Growth - الأكثر طلباً):** 2,150 ج.م (15 ريلز فيديو AI + 25 بوست وتصميم).
  - **باقة التوسع الشامل (Pro Scale):** 3,750 ج.م (30 ريلز فيديو AI + 50 بوست وتصميم).

### 3. تصنيع وطباعة 3D دقيقة (Precision 3D Printing)
- فحص هندسي لملفات النماذج (STL, OBJ, 3MF, STEP, PDF, الصور).
- حساب التكلفة الفعلية للخامة وساعات الطباعة بدون أي مبالغة.
- **شحن موحد وثابت 150 ج.م** لجميع محافظات جمهورية مصر العربية.

## 🛡️ نظام منع التكرار والتحقق البشري الذكي (Anti-Duplicate & Human Verification)
لحماية استفسارات وطلبات العملاء وضمان وصولها لمرة واحدة فقط وبدون تكرار في **Firebase Realtime Database**:
1. **مسار تسجيل موحد (Single Write Pipeline):** حصر الكتابة في الـ backend API عبر معرف فريد (`req_...`) لمنع الإرسال المزدوج من المتصفح.
2. **التحقق البشري التفاعلي (Interactive Math Challenge):** مسألة حسابية سريعة ديناميكية تمنع الإرسال الآلي.
3. **فخ الروبوتات الخفي (Honeypot Trap):** حقل أمني خفي يُسقط فوراً أي روبوتات فحص تلقائي.
4. **مانع النقر المزدوج (Debounce Guard):** قفل زر الإرسال مع فحص مؤقت زمني يمنع التكرار في حال النقر المتكرر.

├── app/                      # موجهات ومكونات صفحات Next.js 14 App Router

│   └── page.tsx              # الصفحة الرئيسية واستعراض الخدمات
├── components/               # مكونات الواجهة التفاعلية (المودال، الأزرار، الترويسة)
├── docs/                     # وثائق البراند والمخططات ودليل الهوية
├── lib/                      # إعدادات Firebase والترجمة وتنسيق العملات
├── public/                   # الأصول العامة والشعارات الرسمية المفرغة
├── scripts/                  # سكربتات التغذية وإعداد المديرين
├── .firebaserc               # ربط مشروع Firebase
├── firebase.json             # إعدادات الاستضافة وقواعد الأمان
└── package.json              # تبعيات وأوامر المشروع
